# Contributing

Keep changes focused. Describe the problem, the change, and how you verified it.

1. Install Node 22.12+ and run `npm ci`.
2. Make your change and run `npm run format` and `npm run check`.
3. For gameplay or rendering changes, complete the manual checks in [development](docs/DEVELOPMENT.md) and attach a short capture or screenshot.
4. Open a pull request with test results and any known limitations.

Preserve chess.js as the rules authority and retain the Move board controls. Do not commit secrets, personal data, recordings, source downloads, or unlicensed assets. Document attribution for any asset changes. Original code contributions are under the MIT license; separate asset licenses remain in force.
